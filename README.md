# zapret-MCEU_modded_by_knox

This is a modded version of **zapret**, originally created by [@bol-van](https://github.com/bol-van/zapret) and [@Flowseal](https://github.com/Flowseal/zapret-discord-youtube). It bypasses DPI blocking and includes the specialized **MC_EU** strategy, which allows connecting to European Minecraft servers.

Это модифицированная версия **zapret**, изначально созданная [@bol-van](https://github.com/bol-van/zapret) и [@Flowseal](https://github.com/Flowseal/zapret-discord-youtube). Она обходит DPI-блокировки и включает специализированную стратегию **MC_EU**, которая позволяет подключаться к европейским серверам Minecraft.

> ⚠️ **IMPORTANT / ВАЖНО**
> 
> **EN:** To use the **MC_EU.bat** strategy, you must first download the official release from the [zapret](https://github.com/Flowseal/zapret-discord-youtube) repository by Flowseal.
> 
> **RU:** Чтобы использовать стратегию **MC_EU.bat**, вам необходимо сначала скачать официальный релиз из репозитория [zapret](https://github.com/Flowseal/zapret-discord-youtube ) от Flowseal.
>
> ## 🎮 Installation & Usage / Установка и использование

### 🔹 MC_EU.bat Strategy / Стратегия MC_EU.bat

**EN:** To use the **MC_EU.bat** strategy, simply download it and place it directly into your main **zapret** folder. To run it, open the file and press **Enter**.  
**RU:** Чтобы использовать стратегию **MC_EU.bat**, просто скачайте её и положите в главную папку **zapret**. Для запуска откройте этот файл и нажмите **Enter**.

> ⚠️ **ATTENTION / ВНИМАНИЕ**
> 
> **EN:** It is not recommended to keep this strategy enabled all the time. Many websites and services (like YouTube or Discord) that usually work with zapret might stop working properly due to the modified routing. Disable it when you are done playing.
> 
> **RU:** Не рекомендуется держать эту стратегию постоянно включенной. Многие сервисы (например, YouTube или Discord), которые обычно работают через zapret, могут перестать работать из-за измененных настроек. Отключайте её после завершения игры.

---

### 🔹 general.list Bypass / Обход сайтов через general.list

**EN:** This mod also includes a modified **general.list** file. It allows you to bypass blocking on essential gaming websites without turning on the MC_EU strategy. To use it, move the downloaded `general.list` into the `zapret/zapret-winws/list` folder and replace the old file.
  
**RU:** Этот мод также включает измененный файл **general.list**. Он позволяет обходить блокировку важных игровых сайтов без включения стратегии MC_EU. Чтобы использовать его, перенесите скачанный `general.list` в папку `zapret/zapret-winws/list` и замените старый файл.
