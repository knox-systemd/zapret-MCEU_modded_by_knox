# zapret-MCEU_modded_by_knox

This is a modded version of **zapret**, originally created by [@bol-van](https://github.com/bol-van/zapret) and [@Flowseal](https://github.com/Flowseal/zapret-discord-youtube). It bypasses DPI blocking and includes the specialized **MC_EU** strategy, which allows connecting to European Minecraft servers.

Это модифицированная версия **zapret**, изначально созданная [@bol-van](https://github.com/bol-van/zapret) и [@Flowseal](https://github.com/Flowseal/zapret-discord-youtube). Она обходит DPI-блокировки и включает специализированную стратегию **MC_EU**, которая позволяет подключаться к европейским серверам Minecraft.

> ⚠️ **IMPORTANT / ВАЖНО**
> 
> **EN:** To use the **MC_EU.bat** strategy, you must first download the official release from the [zapret](https://github.com/Flowseal/zapret-discord-youtube) repository by Flowseal.
> 
> **RU:** Чтобы использовать стратегию **MC_EU.bat**, вам необходимо сначала скачать официальный релиз из репозитория [zapret](https://github.com/Flowseal/zapret-discord-youtube ) от Flowseal.
